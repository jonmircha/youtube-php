## Cómo usar los códigos

Necesitas _PHP_ y, para el curso de _POO_, _MySQL_ o _MariaDB_. Lo más sencillo es instalar un paquete todo en uno como [_XAMPP_](https://www.apachefriends.org/), [_WAMP_](https://www.wampserver.com/) o [_MAMP_](https://www.mamp.info/).

Para correr un ejemplo, entra a su carpeta y levanta el servidor integrado de _PHP_:

```bash
git clone https://github.com/jonmircha/youtube-php.git
cd youtube-php/curso-fundamentos/00_Fundamentos
php -S localhost:8000
```

Cada curso explica en su carpeta qué hay en cada subcarpeta y cómo correr su proyecto final.
