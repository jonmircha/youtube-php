# Curso Fundamentos de _PHP_

En esta carpeta encontrarás los códigos del [Curso Fundamentos de _PHP_](https://www.youtube.com/watch?v=djs_FTTGkDI&list=PLvq-jIkSeTUb2n_YcwsG47RFv69A63hME) de [Jonathan MirCha](https://jonmircha.com/): 27 videos, de la instalación del entorno a las superglobales, con un proyecto final.

| Carpeta                                        | Videos  | Contenido                                                                                                                                                                                                                                  |
| ---------------------------------------------- | :-----: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`00_Fundamentos`](./00_Fundamentos)           | 2 a 24  | La sintaxis, las variables, los tipos de datos, los operadores, los condicionales, los bucles, las funciones, `require` e `include`, las fechas, los archivos y las superglobales: `$_GET`, `$_POST`, `$_FILES`, `$_COOKIE` y `$_SESSION`. |
| [`01_Todo_List_Basico`](./01_Todo_List_Basico) | 25 a 27 | El proyecto final: una lista de tareas que guarda sus datos en un archivo _CSV_, paso a paso, de `index_v1.php` a `index_v6.php`, y terminada en `index.php`.                                                                              |

Para correr cualquiera de las dos, entra a su carpeta y levanta el servidor integrado de _PHP_:

```bash
php -S localhost:8000
```
